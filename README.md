# LocalKart

Alternative Swiggy-style local shop delivery platform.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend
- Node.js
- Express
- TypeScript
- REST API
- JWT
- Socket.IO

### Database
- PostgreSQL
- Prisma

### Maps
- OpenStreetMap
- Leaflet

### AI/ML
- Python
- FastAPI
- Scikit-learn
- Ollama

### Mobile - Phase 2
- React Native
- Expo
- TypeScript
- NativeWind

## Project Structure

- frontend/ - React web application
- backend/ - Node.js API
- docs/ - Architecture and database documentation
- mobile/ - React Native application (Phase 2)
- ai-service/ - AI/ML service (future phase)
